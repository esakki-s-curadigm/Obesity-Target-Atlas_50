# Obesity Target Evidence Atlas (Streamlit)

This folder is a deployment-only package for Streamlit Community Cloud. It includes
the app, curated/filtered evidence tables, the integrated 50-gene master table,
and visualization images. It does not need the original pipeline or raw source CSVs.

## Refresh the deployment package

From the project root, run:

```powershell
python .\build_streamlit_public_app.py
```

The builder copies an explicit allowlist of curated CSVs and charts from `results\`
into this folder. It does not modify the source files in `results\`. It also removes
non-allowlisted CSV copies from this folder's `data\` directory so raw snapshots
aren't accidentally included in this deployment bundle.

## Publish a public app

1. Review the files in this folder, especially `data\`. This app and its bundled
   curated records will be accessible to anyone who can reach the public app.
2. Create a **new public GitHub repository** for this app. Upload the *contents of
   this folder* to the repository root; do not upload the full project or `results\`.
   Include the hidden `.streamlit\config.toml` file if uploading through GitHub Desktop
   or Git; it sets the app's green visual theme.
3. Sign in to [Streamlit Community Cloud](https://share.streamlit.io/) with the
   GitHub account that can access the new repository.
4. Choose **Create app** (or **New app**), select the repository, branch `main`,
   and set the main file path to `app.py`.
5. Select **Deploy**. Streamlit builds the app and gives it a `*.streamlit.app`
   URL after deployment succeeds. Open the URL and share it with viewers.

The app's permanent public URL is generated by Streamlit during deployment; it
cannot be reserved or generated from this local project. A public app means that
the app and its bundled data are not private. Do not deploy confidential or
identifiable data. If access should be restricted, use a private repository/app
and invite viewers instead, subject to the current Community Cloud account options.

## What's included

- Evidence overview with interactive charts, gene focus, and evidence search.
  Hover over chart marks to see evidence details; use the filters to focus on a gene.
- Integrated master table and source-specific tabs for UniProt, Open Targets,
  GWAS Catalog, PubMed, Reactome, GTEx, and ChEMBL
- Sortable/filterable tables and CSV downloads
- Curated source-specific subsets; the raw CSV files remain in the project results
  folder and are not part of this deployment package

The relative evidence index is a prioritization aid, not a causal probability or
clinical efficacy score.
